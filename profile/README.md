## 📦 Featured Work

### 🎬 RenderGuard

https://github.com/apurba-labs/renderguard

Agentic production control system for GPU-intensive media rendering workloads.

Built with **Gemini 2.5 Flash, Google ADK, Vertex AI, Grafana Cloud, Grafana MCP, Prometheus, Loki, and OpenTelemetry**.

RenderGuard investigates production failures, applies deterministic remediation policy, executes narrowly scoped actions, and independently verifies recovery through observability.

**Live Demo:** https://renderguard.gotihub.com

> Gemini reasons. Policy authorizes. The pipeline acts. Grafana independently verifies.
